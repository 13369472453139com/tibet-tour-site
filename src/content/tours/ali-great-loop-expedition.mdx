# 阿里大环线探险之旅

## 行程概览

阿里大环线是西藏最壮丽的越野路线，串联起神山冈仁波齐、圣湖玛旁雍措、古格王朝遗址、札达土林、班公措等世界级景观。全程约3000公里，平均海拔4500米以上，适合有高原经验的探险者。

## 详细行程

### 第1天：拉萨集合
- 抵达拉萨（3650米），适应高原
- 自由活动：八廓街、大昭寺
- 住宿：拉萨四星级酒店

### 第2天：拉萨 → 羊卓雍措 → 日喀则（360km，约6h）
- 翻越岗巴拉山口，俯瞰羊卓雍措
- 途经卡若拉冰川、江孜宗山古堡
- 住宿：日喀则（3800米）

### 第3天：日喀则 → 珠穆朗玛峰大本营（340km，约7h）
- 参观扎什伦布寺
- 经嘉措拉山口、加乌拉山口，远眺5座8000米级雪山
- 抵达珠峰大本营（5200米），观日落金山
- 住宿：绒布寺附近帐篷或招待所

### 第4天：珠峰 → 萨嘎（300km，约6h）
- 清晨拍摄珠峰日出
- 穿越希夏邦马保护区，远眺佩枯措
- 住宿：萨嘎（4500米）

### 第5天：萨嘎 → 玛旁雍措 → 普兰（550km，约8h）
- 沿G219国道西行，进入阿里地区
- 圣湖玛旁雍措、鬼湖拉昂措、神山冈仁波齐
- 住宿：普兰（3900米）

### 第6天：普兰 → 札达（330km，约6h）
- 游览科迦寺
- 穿越札达土林，拍摄夕阳下的土林奇观
- 住宿：札达（3700米）

### 第7天：札达 → 古格王朝 → 狮泉河（250km，约5h）
- 清晨拍摄古格王朝遗址日出
- 参观托林寺
- 下午抵达阿里首府狮泉河镇（4300米）
- 住宿：狮泉河

### 第8天：狮泉河 → 班公措 → 日土（150km，约3h）
- 班公措湖心鸟岛，乘船观鸟
- 日土岩画
- 住宿：日土（4250米）

### 第9天：日土 → 改则（480km，约7h）
- 穿越羌塘无人区边缘，藏羚羊、野牦牛等野生动物
- 住宿：改则（4415米）

### 第10天：改则 → 尼玛（350km，约6h）
- 途经洞措、达瓦措，一措再措
- 住宿：尼玛（4500米）

### 第11天：尼玛 → 文布南村 → 当惹雍措（120km，约3h）
- 探访象雄文明遗址，当惹雍措湖畔徒步
- 住宿：文布南村（4600米）

### 第12天：文布南村 → 班戈（450km，约7h）
- 色林措（西藏最大咸水湖）
- 住宿：班戈（4700米）

### 第13天：班戈 → 纳木措 → 拉萨（360km，约6h）
- 纳木措北岸圣象天门（若开放）
- 翻越那根拉山口，返回拉萨
- 结束行程

- 住宿：12晚（酒店/招待所）
- 门票：行程所列景点首道门票
- 司机兼导游、户外保险

## 费用不含

- 餐饮（AA制，约80-150元/天）
- 个人边防证办理
- 单房差（如有）

## 注意事项
1. 需提前在户籍地办理边防证（填写“西藏自治区日喀则市、阿里地区”）
2. 建议携带：睡袋（-10℃）、保温杯、防晒霜、墨镜、常用药品
3. 高原反应：行进节奏宜慢，备氧气瓶及抗高反药物
4. 最佳季节：5-10月，其中7-8月雨季可能遇泥石流
5. 尊重当地宗教习俗，不随意拍摄僧侣和朝圣者
