# 山南藏文化溯源之旅

## 线路亮点
- 走进西藏文明的摇篮——山南
- 朝圣西藏第一座宫殿：雍布拉康
- 探访西藏第一座佛法僧俱全的寺庙：桑耶寺
- 仰望“西藏第一块农田”与第一代藏王故里
- 体验雅砻河谷的田园与信仰

## 行程概览

### 第1天：拉萨 → 泽当（约180公里）
- 上午：拉萨出发，沿雅鲁藏布江前往山南
- 下午：参观**昌珠寺**（文成公主驻足地，镇寺之宝珍珠唐卡）
- 傍晚：抵达泽当，入住酒店，适应海拔
- 住宿：泽当镇（海拔约3560米）

### 第2天：泽当 → 雍布拉康 → 藏王墓 → 泽当
- 上午：前往**雍布拉康**（西藏第一座宫殿，松赞干布与文成公主夏宫）
- 中午：返回泽当午餐
- 下午：参观**藏王墓**（吐蕃王朝历代赞普陵墓群）
- 傍晚：自由逛泽当老街，体验当地甜茶与藏面
- 住宿：泽当镇

### 第3天：泽当 → 桑耶寺 → 青朴修行地 → 泽当
- 上午：前往**桑耶寺**（西藏第一座剃度僧人出家的寺院，建筑融合汉藏印风格）
- 中午：桑耶镇简餐
- 下午：徒步或乘车前往**青朴修行地**（莲花生大师、寂护大师修行圣地）
- 傍晚：返回泽当
- 住宿：泽当镇

### 第4天：泽当 → 雅砻河谷 → 拉萨
- 上午：参观**西藏第一块农田**（索当农田）与**第一代藏王聂赤赞普故里**
- 中午：泽当午餐
- 下午：返回拉萨，结束行程

## 费用说明
- 包含：全程旅游车、3晚舒适型酒店、行程所列景点门票、导游服务、旅游意外险
- 不含：拉萨往返大交通、餐费（可AA或自理）、个人消费

## 温馨提示
- 山南海拔约3500-3800米，建议提前在拉萨适应1-2天
- 尊重当地宗教习俗，寺庙内禁止拍照
- 最佳旅行季节：4月-10月
- 建议携带：防晒霜、墨镜、帽子、润唇膏、保温杯
